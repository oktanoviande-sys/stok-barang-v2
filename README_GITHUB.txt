STOK BARANG V2 - BUILD APK DARI HP

1. Buat akun GitHub di https://github.com
2. Buat repository baru, misalnya: stok-barang-v2
3. Upload SEMUA isi folder project ini ke repository (termasuk folder .github).
4. Pastikan file .github/workflows/build-apk.yml terlihat di GitHub.
5. Buka tab Actions.
6. Pilih "Build Android APK".
7. Jika workflow belum berjalan, pilih "Run workflow".
8. Tunggu sampai selesai dengan status hijau.
9. Buka hasil workflow tersebut.
10. Di bagian Artifacts pilih "StokBarangV2-APK" untuk mengunduh APK.
11. Ekstrak ZIP artifact bila perlu, lalu instal app-debug.apk di Android.

GitHub Actions menjalankan build di mesin cloud; HP hanya dipakai untuk mengelola repository dan mengunduh hasil APK.
